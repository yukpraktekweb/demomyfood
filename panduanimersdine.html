Panduan Setup iMersDine

Ikuti 5 langkah mudah ini untuk membuat aplikasi kasir & web order Anda online.

1

Salin File & Siapkan Database

Pertama-tama, kita harus menyiapkan tempat penyimpanan data Anda (Database).

  • Buka link Google Spreadsheet yang sudah kami berikan.
  • Klik menu File > Buat Salinan (Make a Copy).
  • Di file hasil salinan Anda, klik menu khusus "⚙️ iMersDine App" di bagian atas.
  • Pilih "1. Setup Database Baru" (Beri izin/Otorisasi jika diminta).
  • Pilih "2. Insert Dummy Data" (Opsional, untuk isi menu contoh).
2

Deploy Apps Script (Backend)

Ubah spreadsheet Anda menjadi sistem yang bisa berkomunikasi dengan web.

  • Klik menu Ekstensi > Apps Script.
  • Di pojok kanan atas, klik tombol biru Terapkan (Deploy) > Penerapan Baru.
  • Klik ikon gerigi ⚙️ (Pilih Jenis), centang Aplikasi Web.
  • Pada bagian Akses, WAJIB pilih "Siapa saja" (Anyone).
  • Klik Terapkan (Beri izin otorisasi lanjutan jika diminta).
3

Copy URL Web App

Setelah proses Deploy berhasil, Anda akan mendapatkan sebuah link.

Salin (Copy) "URL Aplikasi Web" Anda.

Contoh: https://script.google.com/macros/s/.../exec. Simpan baik-baik URL ini.

4

Sambungkan di GitHub

Kita harus menghubungkan tampilan web dengan database Anda.

  • Buka akun GitHub Anda dan buat Repository baru (misal: toko-saya).
  • Upload file index.html ke dalam repository tersebut.
  • Klik file tersebut, lalu klik ikon Pensil ✏️ (Edit).
  • Cari teks const APPS_SCRIPT_URL = '...'; (biasanya di bagian agak bawah).
  • Hapus URL lama dan Paste URL Web App Anda (dari Langkah 3) di dalam tanda kutip.
  • Scroll ke bawah dan klik tombol hijau Commit changes.
5

Online-kan dengan Vercel (Gratis)

Langkah terakhir, membuat web Anda bisa diakses oleh pelanggan.

  • Buka Vercel.com dan login menggunakan akun GitHub Anda.
  • Klik Add New > Project.
  • Cari repository GitHub Anda tadi (misal: toko-saya), lalu klik tombol Import di sebelahnya.
  • Biarkan semua pengaturan default, langsung klik tombol biru Deploy.
  • Tunggu proses selesai. Selamat, Web Anda sudah Online! 🎉

Cara Login Admin / Kasir

Buka web Anda yang sudah online di Vercel. Untuk masuk ke dashboard Admin, ikuti trik rahasia ini:

  1. Klik Icon Logo / Sendok Garpu di pojok kiri atas secara cepat sebanyak 7 Kali.
  2. Masukkan PIN default: 123456
  3. Silakan atur menu, ubah PIN, dan percantik tampilan web Anda dari dalam Dashboard!
