Panduan Instalasi iMersDine

Langkah demi langkah mengatur Backend (Google Sheets) dan Frontend (Vercel) Anda.

Bagian 1: Setup Backend (Google Sheets)

1

Salin File Spreadsheet

Buka link Google Sheets yang Anda dapatkan di Halaman Akses. Klik tombol biru "Buat salinan" (Make a copy) untuk menyimpannya ke Google Drive Anda sendiri.

2

Buka Google Apps Script

Pada file Spreadsheet salinan Anda, klik menu "Ekstensi" (Extensions) di bagian atas, lalu pilih "Apps Script". Tab baru akan terbuka menampilkan kode (Code.gs).

3

Deploy sebagai Aplikasi Web (Web App)

  1. Di editor Apps Script, klik tombol biru "Terapkan" (Deploy) di pojok kanan atas.
  2. Pilih "Penerapan baru" (New deployment).
  3. Klik ikon gerigi (Pilih jenis) dan centang "Aplikasi web" (Web app).
  4. Beri deskripsi (misal: "Versi 1").
  5. Di bagian "Akses" (Who has access), WAJIB pilih "Siapa saja" (Anyone).
  6. Klik "Terapkan" (Deploy).
4

Otorisasi Akses

Jika muncul pop-up otorisasi (Authorization required):

  1. Klik "Tinjau Izin" (Review permissions).
  2. Pilih akun Google Anda.
  3. Jika muncul peringatan "Google belum memverifikasi...", klik "Lanjutan" (Advanced) di bawah.
  4. Klik tulisan "Buka (tidak aman)" (Go to... unsafe) di bagian paling bawah.
  5. Klik "Izinkan" (Allow).
5

Simpan URL Apps Script

Setelah berhasil deploy, Anda akan mendapatkan URL Aplikasi Web (berakhiran `/exec`). Copy (Salin) URL tersebut dan simpan di Notepad. Anda akan membutuhkannya di Bagian 2.

Bagian 2: Setup Frontend (File HTML)

1

Edit File Index.html

Buka file Index.html (yang Anda download dari Halaman Akses) menggunakan aplikasi teks editor seperti Notepad (Windows), TextEdit (Mac), atau VS Code.

PERHATIAN PENTING:

Cari baris kode const APPS_SCRIPT_URL = '...'; (biasanya ada di bagian bawah sebelum tag script selesai). Ganti URL di dalam tanda kutip tunggal tersebut dengan URL Aplikasi Web (Web App) yang Anda dapatkan di Langkah 5 Bagian 1.

Setelah diganti, Simpan (Save) file tersebut.

2

Upload ke Vercel (Gratis)

  1. Buka vercel.com dan buat akun / login (disarankan pakai akun GitHub).
  2. Buat folder baru di komputer Anda, masukkan file Index.html yang sudah diedit ke dalam folder tersebut.
  3. Di dashboard Vercel, klik tombol "Add New" -> "Project".
  4. Pilih opsi "Upload a directory" (atau drag-and-drop folder Anda).
  5. Beri nama project Anda (misal: "toko-kuliner-ku").
  6. Klik "Deploy".
3

Aplikasi Siap Digunakan!

Vercel akan memberikan link domain gratis (misal: toko-kuliner-ku.vercel.app). Buka link tersebut, dan aplikasi iMersDine Anda sudah online dan terhubung dengan Google Sheets Anda!
